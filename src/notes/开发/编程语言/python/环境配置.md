### 虚拟环境管理工具

uv/venv/virtualenv/pipenv



venv(python 自带，简单使用推荐)

```
# 新建虚拟环境
python3 -m venv .venv
source .venv/bin/activate


# 安装依赖
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

python -m pip install requests 
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple

# 推出虚拟环境
deactivate
```



#### uv（更推荐）

```
# 创建一个项目
# uv init
uv init 只负责声明项目
当你运行 uv init 时，它的核心任务是初始化项目的元数据结构。它会创建：
	pyproject.toml：项目的配置文件（相当于项目的“身份证”）。
	.python-version：指定项目使用的 Python 版本。
	hello.py 或 README.md：基础模板文件。

# 虚拟环境
当执行完 uv init 时，你可以手动执行 uv venv,也可以不需要,当你安装包（uv add xx）时它自动会创建出来;


# 当你不需要建项目，只是需要一个虚拟环境时，可以单独执行 uv venv 命令；
# 在某个目录使用 uv venv 命令产生 .venv 文件夹，这个目录就是一个虚拟环境了，只要使用 uv run/uv pip 等命令都相当于在这个虚拟环境下执行；

# uv venv VS uv init
uv venv 是创建虚拟环境；
uv init 是创建一个用 uv 来管理的项目；

# 安装
curl -LsSf https://astral.sh/uv/install.sh | sh

# 使用
# 配置国内源
export UV_DEFAULT_INDEX="https://mirrors.aliyun.com/simple/"
export UV_INDEX_URL="https://mirrors.aliyun.com/simple"

# 初始化项目
uv init my_project


# 虚拟化环境
uv venv                # 默认创建在 .venv
uv venv --python 3.9   # 创建指定版本的环境
uv run python --version # 查看 python 版本


# 运行
uv run  main.py



# 依赖管理
uv add requests        # 添加生产依赖
uv add pytest --dev    # 添加开发依赖
uv remove requests     # 删除依赖
uv tree
uv pip list
uv pip show <package>


# python 管理
uv python install 3.10 3.12
uv python list
uv python pin 3.11
uv python find # 查看当前正在使用的 Python 路径


# 根据 pyproject.toml 生成 uv.lock,lock 文件要进 git
uv lock
# uv.lock 的作用：环境的“快照”
pyproject.toml 里你可能写 requests >= 2.31.0，这是一个范围。而 uv.lock 会记录下你安装的具体版本（例如 2.32.3）以及该包的所有子依赖和哈希值。

# 通过 pyproject.toml 按照依赖
uv sync
uv sync --frozen

# 这俩命令的区别
uv sync (默认行为：同步并更新)
这是最常用的命令。它的逻辑是：
	检查 pyproject.toml 是否发生了变化。
	如果有变化（比如你手动改了版本号），它会重新计算依赖，并更新 uv.lock 文件。
	最后将 .venv 虚拟环境调整到与 uv.lock 一致。

uv sync --frozen (严格只读模式)
它的逻辑是：
	完全忽略 pyproject.toml 的潜在变化，直接读取现有的 uv.lock。
	绝不更新 uv.lock 文件。
	如果 pyproject.toml 和 uv.lock 不一致（例如你改了配置但没运行过普通 sync），它会报错退出，而不是去修复它


# pyproject.toml 配置国内源

[[tool.uv.index]]
name = "aliyun"
url = "https://mirrors.aliyun.com/pypi/simple/"
default = true
```

参考

https://docs.astral.sh/uv/



#### pipenv（推荐）

```
# 安装 pipenv
pip install pipenv

# 创建虚拟环境（在项目目录下）
pipenv --python 3.8

# 激活虚拟环境
pipenv shell

# 安装依赖包
pipenv install package_name
pipenv install grpcio==1.27.2 -i https://pypi.tuna.tsinghua.edu.cn/simple
# 配置国内源，还有一种办法就是在配置文件里声明
export PIPENV_PYPI_MIRROR="https://pypi.tuna.tsinghua.edu.cn/simple/"

Pipfile
[[source]]
url = "https://pypi.tuna.tsinghua.edu.cn/simple"
verify_ssl = true
name = "pypi"


# 国内源
https://zhuanlan.zhihu.com/p/6150454820

# 卸载依赖包
pipenv uninstall package_name

# 退出虚拟环境
exit

# 删除虚拟环境
pipenv --rm

# 显示虚拟环境安装路径
pipenv --venv

# 显示包依赖关系
pipenv graph

# 
pipenv lock
```
