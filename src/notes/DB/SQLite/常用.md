# 基础

### 部署

只需要安装 sqlite 命令就可以了；

服务直接使用 prod_data.db 这个文件即可访问数据库。

### 常用命令

创建

```
# 创建/打开库
sqlite3 prod_data.db
```

SQLite 的命令主要分为两部分：**点命令 (Dot-commands)** 和 **标准 SQL 语句**。

基础管理命令（点命令）

| **命令**                   | **功能**                                               |
| -------------------------- | ------------------------------------------------------ |
| **`.help`**                | 显示所有点命令的帮助列表。                             |
| **`.databases`**           | 列出当前连接的所有数据库（包括主数据库和附加数据库）。 |
| **`.tables`**              | 列出当前数据库中的所有表名。                           |
| **`.schema <table_name>`** | 显示指定表的建表语句（查看结构）。                     |
| **`.header on/off`**       | 开启或关闭查询结果的首行标题显示。                     |
| **`.mode column`**         | 将输出设置为对齐的列模式（阅读感更好）。               |
| **`.read <file.sql>`**     | 执行外部 SQL 文件中的命令。                            |
| **`.exit`** 或 **`.quit`** | 退出 SQLite 提示符。                                   |
