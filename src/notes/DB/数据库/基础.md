# 基础





## 数据库分类

数据库通常根据**数据模型、存储结构和应用场景**划分为以下几个主要大类。每种类型都是为了解决特定类型的数据存储与检索问题而设计的：

#### 1. 关系型数据库（RDBMS / 行式数据库）

最传统、使用最广泛的数据库类型，数据以二维表（行和列）的形式组织，表与表之间通过外键建立关联。支持严格的 **ACID 事务**（原子性、一致性、隔离性、持久性）。

- **核心特点：** 适合处理高度结构化的数据，强一致性，支持复杂的 SQL 关联查询（`JOIN`）。
- **存储方式：** 通常为**行式存储**（数据按行连续存放）。
- **代表产品：** MySQL、PostgreSQL、Oracle、Microsoft SQL Server、SQLite。
- **适用场景：** 电商订单交易、银行金融账户、CRM/ERP 系统、用户权限管理等要求数据绝对准确和事务一致的场景（OLTP）。

#### 2. 列式数据库（Column-Oriented DB / 分析型数据库）

专门为**海量数据分析与报表统计（OLAP）\**设计的数据库。数据在磁盘上\**按“列”连续存储**，而不是按“行”。

- **核心特点：** 压缩率极高，读取特定列时扫描磁盘极少，配合 CPU 向量化计算，聚合查询（`SUM`, `COUNT`, `GROUP BY`）速度极快。
- **代表产品：** ClickHouse、Apache Doris、StarRocks、Amazon Redshift、Cassandra（宽列）。
- **适用场景：** 大数据分析、BI 商业智能报表、用户行为埋点分析、海量日志存储（如 Langfuse、OpenTelemetry 观测日志）。

#### 3. 非关系型数据库（NoSQL）

随着互联网海量数据和高并发需求兴起，NoSQL 放弃了部分传统关系型数据库的严格约束（如灵活的 Schema、最终一致性），换取极致的扩展性与读写性能。主要包含以下 4 个子类：

| **子类别**                   | **核心特点**                                                 | **代表产品**                      | **适用场景**                                             |
| ---------------------------- | ------------------------------------------------------------ | --------------------------------- | -------------------------------------------------------- |
| **键值数据库 (Key-Value)**   | 通过唯一的 Key 极速查找 Value，数据通常保存在内存中          | Redis, Memcached, RocksDB         | 高级缓存、分布式 Session、排行榜、计数器                 |
| **文档数据库 (Document)**    | 数据以 JSON / BSON 等半结构化文档形式存储，Schema 极度灵活   | MongoDB, CouchDB                  | 内容管理系统（CMS）、电商商品详情、用户配置              |
| **图数据库 (Graph)**         | 以“节点（Node）”和“边（Edge）”存储实体及其复杂关联关系       | Neo4j, ArangoDB, NebulaGraph      | 社交关系链、金融风控洗钱分析、知识图谱                   |
| **时序数据库 (Time-Series)** | 针对带时间戳的数据进行极致优化，写入吞吐高，支持时间窗口聚合 | InfluxDB, TimescaleDB, Prometheus | 物联网（IoT）设备监控、应用性能监控（APM）、金融行情数据 |

#### 4. 向量数据库（Vector DB）

随着人工智能（AI）和大语言模型（LLM）爆发而快速兴起的新型数据库。

- **核心特点：** 专门存储由 AI 模型生成的**高维向量（Embedding）**，提供**空间距离与语义相似度检索（ANN 搜索）**。
- **代表产品：** Milvus、Pinecone、Qdrant、Chroma、Weaviate。
- **适用场景：** 大模型 RAG（检索增强生成）知识库、图片/音视频相似度搜索、智能推荐系统。

#### 5. 混合/新兴数据库类型

除了上述主流分类外，业界近年来演化出了几种新型混合数据库：

- **HTAP 数据库（混合事务与分析处理）：** 试图在一套数据库中同时兼顾行存（处理交易）和列存（处理分析）能力，如 **TiDB**、**OceanBase**。
- **云原生 / 分布式数据库：** 采用存储与计算分离架构，具备弹性扩缩容能力，如 **Amazon Aurora**、**CockroachDB**。
- **搜索引擎（Search Engines）：** 采用倒排索引（Inverted Index），专门用于海量文本全文检索，如 **Elasticsearch**、**OpenSearch**。
