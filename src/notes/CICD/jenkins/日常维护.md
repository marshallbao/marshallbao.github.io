### 插件管理

使用  Plugin Usage 来查看插件的使用情况

具体有以下两个模块

Jobs by Plugin

列出每个已安装插件被具体任务（Job）直接调用的情况。

Other Plugins

列出未在单个任务（Job）的配置中直接调用的“其他”插件，这些插件通常是为 Jenkins 提供全局服务的而不是针对特定 Job；

#### 安装插件

直接使用 UI 安装，如果安装失败根据提示手动下载插件，然后 copy 到对应目录；

kubealp -n cicd cp blueocean-bitbucket-pipeline.hpi jenkins-0:/var/jenkins_home/plugins/blueocean-bitbucket-pipeline.hpi

如果一个插件更新时间太长，大概率是 "卡住了" ，需要重启 jenkins；
